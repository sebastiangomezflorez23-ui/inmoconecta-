# Servidor de InmoConecta

Pendiente de implementar con Java, Spring Boot y MySQL.

Para completar HU-01 se requiere:
- Validar los datos recibidos y los roles permitidos.
- Guardar los usuarios en MySQL.
- Rechazar correos duplicados.
- Proteger las contraseñas mediante hash con salt.
- Devolver respuestas de éxito o error al formulario.

Las credenciales de la base de datos no deben subirse al repositorio.
